# Projet Live-chat - intégration à Discord type shit



Le live chat est une fonctionnalité qui sert à envoyer des son, image, texte, vidéo en overlay sur l'écran d'un ami.

On a d'abord un panneau depuis lequel on peut accéder à plusieurs paramètres : 

* Est ce que j'accepte de recevoir du live-chat (si je met non alors je ne peux pas en envoyer)
* La liste de mes amis avec un toggle live chat (si je refuse que quelqu'un m'en envoi je ne peux pas lui en envoyer)
* Accepter les live-chat quand je suis en plein écran exclusif (si oui alors l'utilisateur sera sorti du plein écran exclusif pour afficher le live-chat, si le live-chat est juste un son on le fait pas, on joue le son)
* Définir un cooldown entre un live-chat que je reçoit et la prochaine fois qu'on peut m'en envoyer un



Je peux envoyer un live chat : Bouton envoyer un live chat -> liste des ami à qui je peux en envoyer un -> Zone de configuration du live chat



Dans la zone de configuration du live-chat j'ai accès à un cadre qui représente l'écran, je peux :

* Définir la durée du live-chat
* Ajouter une vidéo, la redimentionner et la placer sur l'écran
* Ajoute un texte, choisir une police d'ecriture et taile de police et deplacer le texte
* Ajouter une image, la redimensionner et positionner sur l'écran
* Ajouter un son, choisir le durée, à combien de temps dans le livre chat il commence

Une fois configuré, je peux si je le souhaite, enregistrer le live-chat pour le réutiliser plus tard, puis l'envoyer à l'utilisateur



Je peux envoyer un live chat : Bouton envoyer un live chat -> liste des ami à qui je peux en envoyer un -> Utiliser un live-chat enregistré

* Quand je veux envoyer un live chat, après avoir sélectionné l'utilisateur je peux directement lui envoyer un live-chat personnalisé ou alors le modifier avant de l'envoyer (ça ne modifie pas la version enregistré sauf si je fait "enregistrer les modification" (comme pour l'enregistrer la première fois) avant de l'envoyer.



Je peux aussi configurer et enregistrer un live-chat pour le préparer pour l'envoyer plus tard, je peux aussi modifier ceux qui sont déjà enregistrés
